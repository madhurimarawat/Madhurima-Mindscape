Python Web Scrapers with Streamlit

November 17, 2026

Web scraping is a useful technique for collecting information from websites. Whether you want to extract textual content, discover embedded links, retrieve PDF documents, or download images, Python provides several libraries that make these tasks easier.

However, running scraping scripts through a command-line interface can sometimes make the process less convenient, especially when you want to perform different extraction tasks without repeatedly modifying your code.

In this tutorial, we will explore a Python project that combines web scraping libraries with Streamlit to provide an interactive interface for extracting website data. The application brings several scraping and downloading features together in one place, making data extraction more accessible.

Web Scraper application built using Python and Streamlit. (Try the Application)

The application provides options for extracting website text, collecting embedded links, retrieving PDF content, and downloading PDF and image files. All these features are accessible through a common Streamlit interface.

"The goal of this project is to simplify website data extraction by bringing text scraping, PDF extraction, and image downloading features into a single application."

🌐 1. What is Web Scraping?

Web scraping is the process of automatically collecting information from websites. Instead of manually opening web pages and copying their contents, a Python program can retrieve website data and extract the information required.

Websites contain different kinds of information, including:

  • Textual content such as headings, paragraphs, and descriptions.
  • Links that redirect users to other web pages.
  • PDF documents embedded or linked within a website.
  • Images available on individual pages.

Python provides libraries such as Requests, Beautiful Soup, and lxml that can help retrieve and process website content. Additional libraries can be used to work with PDF documents and downloaded files.

In this project, these capabilities are presented through a Streamlit interface, so users can access different extraction features without having to interact directly with individual Python scripts.

💡 My tip: Before starting a scraping task, identify the type of information you want to collect. This makes it easier to choose the appropriate libraries and extraction approach.

📌 2. Project Overview

The Web Scraper Functions project is a Python application developed using Streamlit. It provides a user-friendly interface for extracting text, images, and PDF files from websites.

Rather than focusing on only one type of website content, the application provides multiple extraction options.

The major capabilities of this project include:

  • Embedded Links: Extracts links available within a website.
  • Main Website Text Data: Retrieves the primary textual content from the main website.
  • Main Website Text Data along with Embedded Links Text Data: Combines textual content from the main website with text data from its embedded links.
  • Complete Website Text Data: Retrieves textual content across the website.
  • Extract Text from PDF Link: Extracts text from a PDF using a provided PDF link.
  • Main Website PDF Data along with Embedded Links PDF Data: Combines PDF text extracted from the main website with PDF data available through embedded links.
  • Complete Website PDF Data: Retrieves PDF data available across the website.
  • Complete Website Text and PDF Data: Presents both textual and PDF data collected from the website.
  • Download PDF Files From Main Website: Allows selective downloading of PDF files from the main website.
  • Download All PDF Files From Website: Supports downloading all PDF files available across the website.
  • Download Image Files From Main Website: Allows downloading image files from the main website.
  • Download All Image Files From Website: Supports downloading all image files available across the website.

These features make the application useful for collecting different types of website information through a single interface.

🛠️ 3. Tools and Technologies Used

The project uses Python libraries for retrieving website content, parsing HTML, processing PDF documents, and managing downloaded files. Streamlit provides the application interface.

Development Environment

  • PyCharm: An IDE used for writing and executing Python code.
  • Streamlit: A Python framework used to create the interactive web application.

Libraries Used

  • Streamlit: Simplifies the development of interactive Python web applications. It provides ready-to-use interface components that can be created directly from Python code.
  • Requests: A Python library for making HTTP requests. It helps retrieve website content and communicate with web servers.
  • lxml: A library for processing HTML and XML documents. It provides tools for parsing and working with structured document data.
  • Beautiful Soup (bs4): A Python library used to parse HTML and XML documents and extract useful information such as text and links.
  • PyPDF2: A Python library for working with PDF documents, including extracting text and handling PDF files.
  • io: Python's built-in input/output module, which provides tools for working with streams and in-memory data.
  • zipfile: Python's built-in module for creating, reading, and extracting ZIP archives.

Together, these libraries provide the tools required for the different data extraction and file-handling features available in the project.

💡 My tip: Understanding the purpose of each library makes it easier to maintain the project and extend its functionality.

📚 5. Installing the Required Libraries

Once the development environment is ready, install the libraries required by the project.

Python packages can be installed using the pip package manager. The general command is:

The project uses the following external libraries: 

pip install streamlit
pip install requests
pip install lxml
pip install beautifulsoup4

The io and zipfile modules are part of Python's standard library, so they do not need to be installed separately.

Make sure the required dependencies are installed in the same Python environment that will be used to execute the application.

💡 My tip: You can also maintain your dependencies in a requirements.txt file. This makes it easier to install all the required packages when setting up the project on another system.

🚀 6. Understanding Streamlit

Streamlit is a Python framework that makes it easier to create and deploy interactive web applications. It is particularly useful for Data Science, Machine Learning, and Python projects that need a user-friendly interface.

One of its main advantages is that developers can create application components directly through Python functions instead of building a separate frontend.

To install Streamlit, execute the following command: 

pip install streamlit

After installation, Streamlit can be used to build an application interface and connect it with Python functionality.

In this project, Streamlit acts as the interface through which users can access the different web scraping and file downloading options.

▶️ 7. Running the Project Locally

After installing the dependencies, we can execute the Streamlit application locally.

Step 1: Open the Project

Open the project directory in PyCharm and make sure the required dependencies are installed.

Step 2: Run the Streamlit Application

Open the terminal inside the project directory and execute: 

streamlit run app.py

Here, app.py represents the Python file containing the Streamlit application. If your main file has a different name, replace app.py with that filename.

Step 3: Open the Application

By default, Streamlit starts its local server on port 8501. Open the following URL in your browser: 

http://localhost:8501

You should now be able to access the application through your browser.

If another Streamlit application is already using the default port, Streamlit can use another available port, such as 8502.

The execution process remains similar for other Streamlit projects. The application code and features may change, but the basic command used to launch the project stays the same.

💡 My tip: Before launching the application, verify that the terminal is using the correct virtual environment.

📝 8. Understanding the Text Extraction Features

One of the main functionalities of this project is extracting textual information from websites.

A website may contain information on its main page as well as additional content available through embedded links. Depending on the extraction option, the application can retrieve different combinations of this information.

Main Website Text Data

This option focuses on retrieving the primary textual content from the main website. It is useful when we only need the information available on the page provided.

Embedded Links

Websites often contain links that direct users to other pages. Extracting these links helps identify additional pages that may contain relevant information.

Main Website Text along with Embedded Links Text

Sometimes, the main page alone does not contain all the information we need. This option combines the main website's textual content with text extracted from its embedded links.

Complete Website Text Data

This option is intended to retrieve textual content across the website rather than limiting extraction to the main page.

These different extraction options make it easier to choose the level of information required for a particular task.

💡 My tip: If you only need information from one page, start with the main website text option. Use broader extraction options when you need content from linked pages.

📄 9. Extracting PDF Data from Websites

Many websites provide useful information in PDF documents, such as reports, guides, documentation, and other downloadable resources.

This project includes PDF extraction features that allow users to retrieve text from PDF documents available through website links.

Extract Text from PDF Link

This feature extracts information from a PDF document using the PDF link provided by the user.

Main Website PDF Data along with Embedded Links PDF Data

Complete Website PDF Data

This feature retrieves PDF data available across the website.

Complete Website Text and PDF Data

☁️ 11. Deploying the Application Using Streamlit

Once the application is working locally, we can deploy it online using Streamlit. This makes the application accessible through a browser without requiring every user to install the project locally.

Step 1: Create a GitHub Repository

Upload the project code to a GitHub repository. Make sure the required Python files and dependency information are included.

Step 2: Open Streamlit

Visit the official Streamlit website and sign in using your GitHub account.

Step 3: Create a New Deployment

Select the option to create a new deployment and provide the details of your GitHub repository.

Step 4: Specify the Application File

Enter the repository name and specify the Python file that should be executed when the application starts.

If your main application file is named streamlit_app.py, Streamlit can use that conventional filename. Otherwise, specify the correct file path.

Step 5: Add Dependencies

Include a requirements.txt file in the repository. This file lists the Python packages required by the application.

For example, the dependencies used by this project can be listed as: 

streamlit
requests
lxml
beautifulsoup4
PyPDF2

You can also specify package versions when your project requires particular versions. Python version compatibility should be configured according to the deployment platform's supported settings.

Step 6: Deploy

After providing the repository, application file, and dependencies, start the deployment process.

Once deployment completes successfully, Streamlit provides a web address through which the application can be accessed and shared.

You can visit the deployed version of this project here: Web Scraper Application.

⚠️ 12. Important Considerations and Limitations

Web scraping applications depend on the availability and structure of the websites being accessed. Before extracting data, it is important to consider the following points:

  • Website Access: Some websites restrict automated requests or require authentication. A scraping application may not be able to retrieve content from every website.
  • Website Structure: The structure and availability of website content can vary. Changes to a website may affect the information that can be extracted.
  • PDF Availability: PDF extraction depends on accessible PDF links and documents that can be processed by the application.
  • Responsible Scraping: Always respect website terms of service, access restrictions, copyright requirements, and applicable laws. Avoid sending excessive requests to websites.
  • Application Resource Limits: The deployed web application has a limit of 100 MB. Once this limit is reached, the application will not be able to scrape additional content. For larger scraping tasks, the README recommends running the application locally.

Keeping these limitations in mind helps users understand what the application can handle and when local execution may be more suitable.
