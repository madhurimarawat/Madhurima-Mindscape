## Features

- **Jekyll-Powered Architecture:** Migrated to Jekyll with organized content, reusable layouts, includes, and structured YAML data.
- **Responsive Design:** Fully responsive interface for desktop, tablet, and mobile devices.
- **Dynamic Themes:** Multiple themes with dynamic, theme-aware colors and styling.
- **Interactive Icon Hero Section:** Font Awesome icons linked to individual blog posts, with an interactive slider and dynamic theme-based colors.
- **Reusable Blog Templates:** Consistent blog layouts and reusable components for managing articles.
- **Reading Time:** Displays estimated reading time for individual blog posts.
- **Read Aloud:** Listen to blog articles using browser speech synthesis.
- **Comment Functionality:** Interactive comment forms with predefined and custom comments, including email-based submission.
- **Save Articles:** Bookmark and unsave blog posts using browser LocalStorage.
- **Share Articles:** Share posts using the Web Share API, Clipboard API, and fallback options.
- **Explore the Blog:** Dedicated page displaying blog previews, titles, and descriptions for easy content discovery.
- **Saved Articles:** Dedicated section to view and manage bookmarked posts.
- **Blog Insights Dashboard:** Displays blog information, categories, tags, and article metadata using structured data and permalinks.
- **Blog Template Library:** Dedicated collection of reusable blog templates with categories, tags, and structured values.
- **SEO Optimization:** Individual YAML SEO metadata, XML sitemap, RSS feed, and `robots.txt`.
- **Custom 404 Page:** Dedicated responsive error page for unavailable URLs.
- **Social & Navigation Links:** Integrated navigation and footer links to LinkedIn, GitHub, Portfolio, and RSS feed.
- **Creative Exploration:** A platform for personal reflections, technology, project diaries, poetry, and photography.

## Directory Structure

```text
Madhurima-Mindscape/
│
├── _data/              # YAML data and SEO metadata for blog pages
├── _includes/          # Reusable components and page imports
├── _layouts/           # Jekyll page layouts
├── _posts/             # Blog articles organized by category
├── blog-tools/         # Saved Articles, Blog Insights, and Blog Templates
│
├── css/                # Stylesheets and theme designs
├── js/                 # JavaScript functionality
├── images/             # Blog images and illustrations
├── website_snapshots/  # Website screenshots and GIF previews
│
├── _config.yml         # Jekyll configuration
├── index.html          # Homepage
├── 404.html            # Custom error page
├── Gemfile             # Ruby dependencies
├── Gemfile.lock        # Locked dependency versions
├── robots.txt          # Search engine crawling instructions
├── LICENSE             # Project license
└── README.md           # Project documentation
```
